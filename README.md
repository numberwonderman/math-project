# Math Project

My starting point for math experiments — the code companion to my 10-week
reading plan (*Experimental Mathematics: A Computational Perspective* ×
*The Ultimate Challenge: The 3x+1 Problem*).

## Layout

- `experiments/` — one script per week.
  - Week 1: reproduce one pi approximation from the text and record error versus work.

## My rules

- 30–45 minutes a session, four sessions a week.
- Save rough results; do not polish.
- Minimum-day rule: if focus is poor, read two pages or run one existing example. That still counts.

Started September 26, 2026.
